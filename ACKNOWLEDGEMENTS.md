# Acknowledgements

ANVIL is built on open standards and the wider open-source engineering community.

## Standards

- **Model Context Protocol (MCP):** the open specification for connecting AI models to local tools and data.
- **OASIS SARIF v2.1.0:** the Static Analysis Results Interchange Format, used for GitHub code scanning and IDE viewers.
- **MADR (Markdown Architectural Decision Records):** the format behind ANVIL's architecture decision records.
