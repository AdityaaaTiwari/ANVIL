# Continuous Learning
At the end of meaningful work:
1. Identify lessons that are **verified** and **durable** (a gotcha, a convention, a decision and its reason).
2. Save each with evidence: `anvil memory add . --kind lesson --content "..." --evidence <file or commit>`.
3. Save a handoff for unfinished work: `anvil memory handoff . --content "..."`.
4. Do not save guesses, secrets or facts that are obvious from the code.
Lessons that keep recurring should become a skill or rule — propose one.
