# /checkpoint

Write a checkpoint named `$ARGUMENTS` with: goal, what is done (with evidence), decisions made and why, open problems, and exact next steps. If the ANVIL CLI is available, also save it with `anvil memory add . --kind decision --content "<decision>" --evidence <files>`.
