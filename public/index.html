FREQUENTLY ASKED QUESTIONS

Everything you need to know.

Does ANVIL automatically apply changes to my code?

No. By design, ANVIL enforces human approval for consequential actions. Patch validation is a dry run that inspects diff structure, and remediation generation produces a plan rather than silently modifying dependencies.

Is ANVIL's local dashboard a hosted web app?

No. The dashboard runs 100% locally on your machine via Node.js and binds to localhost. Your repository source code, AST index, and git history never get uploaded to any external server.

Which languages are supported for deep AST analysis?

TypeScript and JavaScript have native, deep AST and symbol-level analysis. For other languages (Python, Go, Rust, Java), ANVIL provides manifest parsing, configuration audits, script runners, and git change-risk heuristics.

How do I connect ANVIL with Claude Code or Cursor?

ANVIL provides a built-in MCP server (`anvil mcp` or through the CLI). Simply add it to your Claude Code or Cursor configuration file to grant AI assistants read-only access to ANVIL's repository intelligence tools.

What is required to run ANVIL?

ANVIL requires Node.js version 22 or higher. It works seamlessly across macOS, Linux, and Windows PowerShell.

Is ANVIL completely free and open source?

Yes. ANVIL is licensed under the permissive MIT License. You have complete freedom to inspect, fork, contribute, and use it in commercial or open-source projects.
